# Introduction
I'm testing out the Alegreya font for the `utopia` style, since I think it has
just a wonderful, humanist shape---the perfect kind of thing to balance with the
lyrical modernist Utopia (to use Bringhurst's parlance). That said, I don't
think that Alegreya sans will be replacing Merriweather sans, since Merriweather
just seems to match Utopia a bit better---maybe it's because Merriweather is a
*touch* less spindly.
